- Building projects in AI, web, and systems -- some public here, some in private client repos
- Most of my projects are built and shipped entirely from a phone -- no PC, no local IDE. CI/CD pipelines (GitHub Actions, Jenkins, game-ci) do the heavy lifting
- Co-founder @ CodedbyAKSA

### Featured projects

| Project | What it does | Built with |
|---|---|---|
| [Itihaas](https://github.com/stashlop/Itihaas) | Heritage-tourism platform for India -- monument booking, verified tour guides, a merch store, and an AI chatbot for travel info. 8 stars. | Flask, SQLAlchemy, spaCy |
| [Archive-Arcade](https://github.com/stashlop/Archive-Arcade-mini-project) | Full-stack platform combining a books/games catalog, a cafe booking system, and an admin dashboard with revenue analytics. Live demo included. 5 stars. | Node.js, Express |

### Other work (private / client repos)

- **SerialDataApp** -- commercial Java desktop app used by lab and medical/industrial clients to capture autoclave/sterilization data over RS232/USB, generate PDF/CSV reports, and manage license keys. Includes an offline ECDSA P-256 hardware-bound licensing system built from scratch.
- **Hollow Halls** -- a Unity first-person horror maze game, built and shipped via a GitHub Actions + game-ci pipeline (phone-only, no local Unity Editor).
- **HeroBid** -- a Flutter real-time multiplayer auction/battle game with a Firebase Firestore + Realtime Database backend.
